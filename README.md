\# Fire CAD Analyzer 🔥



أداة تحليل ملفات CAD لأنظمة مكافحة الحريق



\## المميزات

\- قراءة ملفات DXF/DWG

\- استخراج تلقائي للعناصر (رشاشات، مواسير، مضخات، صمامات)

\- كشف تلقائي لوحدة القياس

\- فحص التوافق مع NFPA 13 والكود السعودي

\- تقارير JSON و PDF



\## الاستخدام

python src/main.py "path/to/file.dxf" --verbose



\## المتطلبات

\- Python 3.8+

\- ezdxf

\- shapely

\- reportlab
